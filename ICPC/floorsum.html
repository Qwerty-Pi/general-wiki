Floor Sum Function

We are interested about how to compute functions in the form of $$F_P(n, a, b, c) = \sum_{i = 1}^{n} P\Big( i, \Big\lfloor\frac{ai + b}{c}\Big\rfloor \Big)$$ where $P \in \mathbb{F}[x, y]$ is polynomial in two variables. Why, you ask? Because it appears in contests.

There are two different interpretation for this floor sum function: A 2D grid geometry one, which we can rewrite $P\Big( i, \Big\lfloor\frac{ai + b}{c}\Big\rfloor \Big)$ into summation in the y-axis such that the summation is symmetric in $x$ and $y$. Alternatively, there is also a group-theoric one, which is more generic and (possibly more) useful in scenarios.

For the sake of simplicity, we use $F_{h, k} := F_{x^h y^k}$ and $F$ as the function with domain being the collection of matrices $(F_{h, k})$. We also write $P_{h, k} := x^h y^k$.

Normalisation

We definitely don't want to handle the cases where some $a, b$ is negative or greater or equal to $c$, since those cases are ugly. How can we normalise them?

Normalising $a$

Let's say $a$ is not normalised. Write $a = \lambda c + a_0$, then $$ P_{h, k}\Big( x, \Big\lfloor\frac{ax + b}{c}\Big\rfloor \Big) = P_{h, k}\Big( x, \Big\lfloor\frac{a_0x + b}{c}\Big\rfloor + \lambda x \Big) = \sum_{j = 0}^{k} \binom{k}{j} \lambda^{j} P_{h + j, k - j} \Big( x, \Big\lfloor\frac{a_0x + b}{c}\Big\rfloor\Big) $$

The above directly translates to $$ F_{h, k}(n, a, b, c) = \sum_{j = 0}^k \binom{k}{j} \lambda^{j} F_{h + j, k - j}(n, a_0, b, c) $$

This can be naively computed in $O(M^3)$, or with fast convolution in $O(M^2 \log M)$.

Normalising $b$

Similarly, if $b$ is not normalised, then we can write $b = \lambda c + b_0$, and $$ P_{h, k}\Big( x, \Big\lfloor\frac{ax + b}{c}\Big\rfloor \Big) = P_{h, k}\Big( x, \Big\lfloor\frac{ax + b_0}{c}\Big\rfloor + \lambda \Big) = \sum_{j = 0}^{k} \binom{k}{j} \lambda^{j} P_{h, k - j} \Big( x, \Big\lfloor\frac{ax + b_0}{c}\Big\rfloor\Big) $$

Then, $$ F_{h, k}(n, a, b, c) = \sum_{j = 0}^k \binom{k}{j} \lambda^{j} F_{h, k - j}(n, a, b_0, c) $$

Once again work in $O(M^3)$ naively and $O(M^2 \log M)$ with optimisation.

Euclidean Algorithm

First note that for $k = 0$, $F_{h, 0}(n, a, b, c) = \sum_{i = 1}^{n} P_{h, 0}(i, \lfloor \frac{ai + b}{c} \rfloor) = \sum_{i = 1}^{n} i^h = S_h(n)$ is simply the sum of powers. Therefore we only need to think about the case where $k \ge 1$.

We assume that $a, b, c$ are normalised. When $a = 0$, $y$ is irrelevant as $$ F_{h, k}(n, a, b, c) = \sum_{i = 1}^{n} P_{h, k}\Big( i, \Big\lfloor\frac{ai + b}{c}\Big\rfloor \Big) = \sum_{i = 1}^{n} P_{h, k}\Big( i, \Big\lfloor\frac{b}{c}\Big\rfloor \Big) = S_h(n) \cdot P_k\Big( \Big\lfloor\frac{b}{c}\Big\rfloor \Big) $$ But since $\lfloor\frac{b}{c}\rfloor = 0$ and $k \ge 1$, $F_{h, k}(n, a, b, c) = 0$. We may assume $a \gt 0$ in the following.

To write $P$ as summation, we can simply take the partial difference of $P$: $\{\Delta_y P\} (x, y) = P(x, y) - P(x, y - 1)$. Note that $\Delta_y P$ is also polynomial. Hence we have $$ F(n, a, b, c) = \sum_{i = 1}^{n} \sum_{j = 1}^{\lfloor \frac{an+b}{c} \rfloor} \{ \Delta_y P \}( i, j ) \Big[j \le \frac{ai + b}{c}\Big] $$ Indeed, we can rewrite the condition $j \le \frac{ai + b}{c}$ to $i \ge \frac{cj - b}{a}$. Take $m = \lfloor \frac{an + b}{c} \rfloor$, we have $$ F_{h, k}(n, a, b, c) = \sum_{i = 1}^n \sum_{j = 1}^m \{ \Delta_y P_{h, k} \} (i, j) \Big[ i \ge \frac{cj - b}{a} \Big] = S_h(n) \cdot P_k(m) - \sum_{i = 1}^{n} \sum_{j = 1}^{m} \{ \Delta_y P_{h, k} \} (i, j) \Big[ i \le \frac{cj - b - 1}{a} \Big]$$

By the condition of $m = \lfloor \frac{an + b}{c} \rfloor$, $\frac{cm - b - 1}{a} \leq \frac{an - 1}{a} \lt n$. Therefore, $$ \sum_{i = 1}^{n} \sum_{j = 1}^{m} \{ \Delta_y P_{h, k} \} (i, j) \Big[ i \le \frac{cj - b - 1}{a} \Big] = \sum_{j = 1}^{m} \sum_{i = 1}^{n} \{ \Delta_x P_{k, h} \} (j, i) \Big[ i \le \frac{cj - b - 1}{a} \Big] = F_{\text{S}_y \Delta_x P_{k, h}}(m, c, -b - 1, a) $$

Combining, we have $$ F_{h, k}(n, a, b, c) = S_h(n) \cdot P_k(m) - F_{\text{S}_y \Delta_x P_{k, h}}(m, c, -b - 1, a) $$

With normalisation, we can do some "euclidean-like" algorithm to solve the task. Directly doing the above gives a $O(M^4)$ algorithm - there exists optimisations to make it runs faster, but I haven't figure it out yet.

Key Equations

Here are the key equations for $F_{h, k}$ where $k \ge 1$:

(Normalisation of $a$) Suppose $a = \lambda c + a_0$. Then $$ F_{h, k}(n, a, b, c) = \sum_{j = 0}^k \binom{k}{j} \lambda^{j} F_{h + j, k - j}(n, a_0, b, c) $$

(Normalisation of $b$) Suppose $b = \lambda c + b_0$. Then $$ F_{h, k}(n, a, b, c) = \sum_{j = 0}^k \binom{k}{j} \lambda^{j} F_{h, k - j}(n, a, b_0, c) $$

(Euclidean Step) For $a \ne 0$, $m = \lfloor \frac{an + b}{c} \rfloor$, $$ F_{h, k}(n, a, b, c) = S_h(n) \cdot P_k(m) - F_{\text{S}_y \Delta_x P_{k, h}}(m, c, -b - 1, a) $$

Simple Cases

The simplest cases to be considered are $F_{0, 1}, F_{1, 1}$ and $F_{0, 2}$, since $F_{i, 0}$ are just sum of powers. This is the most useful cases and in some templates, and these cases are addressed so as to verify the formula is correct.

Summation over $\big\lfloor\frac{ai + b}{c}\big\rfloor$ ($F_y = F_{0, 1}$)

(Normalisation of $a$) Suppose $a = \lambda c + a_0$. Then $$ F_y(n, a, b, c) = \lambda S_1(n) + F_y(n, a_0, b, c) $$

(Normalisation of $b$) Suppose $b = \lambda c + b_0$. Then $$ F_y(n, a, b, c) = \lambda n + F_y(n, a, b_0, c) $$

(Euclidean Step) For $a \ne 0$, $m = \lfloor \frac{an + b}{c} \rfloor$, $$ F_y(n, a, b, c) = nm - F_y(m, c, -b - 1, a) $$

Summation over $\big\lfloor\frac{ai + b}{c}\big\rfloor^2$ ($F_{y^2} = F_{0, 2}$)

(Normalisation of $a$) Suppose $a = \lambda c + a_0$. Then $$ F_{y^2}(n, a, b, c) = \lambda^2 S_2(n) + \{ 2 \lambda F_{xy} + F_{y^2} \}(n, a_0, b, c) $$

(Normalisation of $b$) Suppose $b = \lambda c + b_0$. Then $$ F_{y^2}(n, a, b, c) = \lambda^2 n + \{ 2 \lambda F_y + F_{y^2} \}(n, a, b_0, c) $$

(Euclidean Step) For $a \ne 0$, $m = \lfloor \frac{an + b}{c} \rfloor$, $$ F_{y^2}(n, a, b, c) = nm^2 - \{ 2F_{xy} - F_y \}(m, c, -b - 1, a) $$

Summation over $i \cdot \big\lfloor\frac{ai + b}{c}\big\rfloor$ ($F_{xy} = F_{1, 1}$)

(Normalisation of $a$) Suppose $a = \lambda c + a_0$. Then $$ F_{xy}(n, a, b, c) = \lambda S_2(n) + F_{xy}(n, a_0, b, c) $$

(Normalisation of $b$) Suppose $b = \lambda c + b_0$. Then $$ F_{xy}(n, a, b, c) = \lambda S_1(n) + F_{xy}(n, a, b_0, c) $$

(Euclidean Step) For $a \ne 0$, $m = \lfloor \frac{an + b}{c} \rfloor$, $$ F_{xy}(n, a, b, c) = S_1(n) \cdot m - \frac{1}{2}\{ F_{y^2} + F_y \}(m, c, -b - 1, a) $$
