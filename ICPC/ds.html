Data Structure

Introduction

What if there is a library of all the data structure that ever existed? Well, that means we can solve every kind of data structure problems! Unfortunately, such does not exist, so our best guess is to maintain a list of well-known techniques and data structures.

Perhaps, it is also a good idea to define abstractly what does the data structure can maintain. By "maintain", it supports a certain set of operations, say insertion, modification, deletion or various queries. We do not exactly care about the transformation that leads to the state where we can apply the data structure here - those are another question.

Most of the time, what we care is whether we can maintain the set of properties without actually maintain the whole thing. Therefore, the set of operations matters, and would affect what kind of data structure is "allowed".

Well-known Data Structures

Binary-Indexed Tree

BIT essentially a rip-off version of segment tree, since it only supports a subset of operations. However, in practice this runs somewhat faster (also easier to code), so sometimes is need.

Abstractly, BIT maintains a set of ranges (where each point is contained in finite # of ranges) where each prefix of the actual array is the disjoin set union of some of the ranges (while segment tree maintains such for each range of the actual array). As long as "subtraction" is well-defined (say +), we can subtract two prefixes to get a range. However, if inverse does not exist (say max), then it would only work for prefix, while time cannot be reversed. (Out of technicality, of course, you directly use the set of ranges to do log^2 BIT range. But why are you doing that?)

For example, range add (+) and prefix max can be done by BIT, and segtree is not needed.

Segment Tree Beats

Key Idea: we can change the break and tag conditions.

1. Convert range chmax to range add on max, amortised on the number of distinct values.

2. Maintain historic values by transforming with auxilary arrays.

Treap

Randomised BST. It is much more flexible than segment tree, and basically can do everything segment tree can do (unless you try to code a persistent treap?? I am not sure how to do that), but naturally it is slower (in practice and implementation) compare to segtree.

Wavelet Tree

Segment Tree on value (??). In each node, maintain for the whole array for which where the node comes from, for computing k-th sorted element from an array range.

Block Decomposition

Sometimes we want to decompose what we maintain into blocks. We can also split the cost to update and query. Most commonly we split sqrt, but most of the time it is just subject to # of updates and # of queries. One of the way is to rebuild everything in a block when the block info is "chaotic" enough.

Task List

General Rule of Thumb: If there is a way to eat some pen without dying (say log / sqrt), try to eat it first to see what will happen, and obtain a seemingly working solution first, then try to optimise it.

Given $A[N]$ ($\le 10^5$) and $V$ ($\le 1000$) where $0 \le A_i \lt V$. Support $Q$ ($ \le 10^5$) queries: (1) Determine whether exists $X \cup Y \subset [L, R]$ where $X, Y$ disjoint, $\sum A_X = \sum A_Y$, (2) $A_i := A_i^3 \mod V$ for $L \le i \le R$. Note that when $R - L + 1 \gt \log_2 V$, then always yes for (1). Hence just brute. $O((N + Q) \log N)$ for segtree, $O(QV)$ for checking.

Array of size $N$ ($\le 10^6$). Support $Q$ ($ \le 10^6$) queries: (1) Range Add, (2) Range Max Range Average (fraction). Observe that the optimal length is either 2 or 3 so can just use segtree maintain.

Given an array of size $N$ ($\le 10^5$). Support $Q$ ($\le 10^5$) queries: Given three ranges, find multiset intersection. Mo's algorithm with bitset (wtf). Split the queries into several parts.

Given $N$ arrays of total length $\le 10^5$. Define the weight of an array to be the number of distinct elements in it. Consider over all possible ways to choose a subarray from each array and merge them together, compute the total sum of weight with point updates. Maintain for each value independently.

Given a sum segment tree. Support (1) Range add, (2) Count nodes completely included in $[L, R]$ and weight $\le X$. Decompose the segtree into $O(\log N)$ different sizes and solve for each in $O(N \sqrt{N} \log{N})$ (wtf?).

Given an array $A$ of length $N$ ($\le 5 \times 10^4$), where $0 \le A_i \lt V$ ($\le 2^{30}$). Support (1) Point update, (2) Shortest length $R - L + 1$ such that $A_L | A_{L + 1} | \dots | A_R \ge K$. Brute-force maintain same-block query and enumerate cutting point for diff-block query: $O(Q \sqrt{N} \log{V})$. Alternatively use segment tree to maintain all the distinct possible $O(N \log^2 V)$ answers.

Given an array $A$ of length $N$. Each round select the max value with min index, say $i$, and subtract one from $A_{i-1}, A_i$ and $A_{i+1}$. Support point update. Spot the condition of ans is $\sum \{ A_x : A_{x-1} \lt A_x \ge A_{x+1}\}$, maintain with segtree trivially.

Given an array $A$. Support $Q$ queries: (1) Count # of factors of range product. Mo's with factorisation.

Given an array $A$. Support $Q$ queries: (1) Mod Add, (2) Range Sum. Can be done by sqrt decomposition, handling large mod and small mod separately.

Given an array $A$. Support $Q$ queries: (1) Append $x$ to $A$, (2) Range Sum, (3) All XOR, (4) Sort Array. Mainly use segtree to maintain, and just mark a prefix as "sorted".

Given a tree of $N$ nodes where each node has a bitwise operators (AND OR XOR) and a value. Support $Q$ queries: (1) Point update, (2) Find walk max where init value is in [0, z]. Consider the bitwise operators as update and add in $\mathbb{F}_2$, actions can be merged trivially with HLD in two logs (LCT in one log???). After all the merging then just maximise the ans.

Given an array $A$. Support $Q$ queries: Determine whether two values $A_i, A_j$ where $L \le i \le j \le R$ and $A_i$ op $A_j = X$ where op is +, -, * or /. For * and /, maintain all the valid pairs. For + and -, Mo with bitset (wtf).

Given an array $A$. Support $Q$ queries: (1) Range query certain rank, (2) Range Add. Sqrt Decomposition + BS on answer.
