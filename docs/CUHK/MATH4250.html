Combinatorial Games

Introduction

Combinatorial Games refers to any two-player alternate perfect-information finite games, which ends at a terminal position after finite moves no matter what strategy is involved.

A combinatorial game is called impartial if the set of choices is the same for both players, and partizan otherwise. Meanwhile, a game is called to be with a normal play rule if the last player moves wins, and misère play rule otherwise.

Zermelo's theorem: Exactly one player has winning strategy for any combinatorial game. Very intuitive and can be proven with induction.

P-positions / N-positions: assume impartial and normal rule, P-position means the previous player at this position wins, and N-position means the next player at this position wins. With Zermelo's theorem, we obviously have $P \sqcup N = V$ with $V$ the whole state space.

We have the following characterisation: (1) All terminal positions are P-positions, (2) P-positions can go to N-positions, (3) N-positions can only go to P-positions. Since by definition the number of positions is finite, as long as these characterisation is satisfied it is the unique set of P/N-positions.

Examples

Subtraction Game: Given a finite set $S \subset \mathbb{Z}^+$ and a positive integer $N$. Each move: select $s \in S$ and subtract $s$ from $N$. Just DP. Take-away Game is a special case with $S = [K]$, then $P = (K + 1) \mathbb{Z}_{\ge 0}$.

Wythoff's Game: Given two positive integers $A$ and $B$ where $A \le B$. Each move: subtract any positive integer or both by the same amount. $P = (\varphi N, (\varphi + 1) N)$. Interestingly this is linked to the Beatty's Theorem, which states that given $\alpha, \beta \gt 1$ and $\alpha^{-1} + \beta^{-1} = 1$ we have $\mathbb{Z} = \{\lfloor \alpha n \rfloor \} \sqcup \{ \lfloor \beta n \rfloor \}$.

Nim Game: Given $N$ integers $A_1, \cdots, A_N$. Each move: subtract any positive integer from any element. $P = \{ (A_1, \cdots, A_N) : \oplus \{ A_i \} = 0 \}$ where $\oplus$ denotes the XOR sum.

Sprague-Grundy (SG) Function

By modelling the game into a DAG $G(V, E)$, we can indeed introduce the SG Function with $g(v) = \text{mex}_{u \in N(v)} \{ g(u) \}$, where mex is the maximum-excluded nonnegative integer. From definition clearly $P = \{ v : g(v) = 0 \}$.

If we define the sum of CG where the player pick one game to play on, surprisingly, the SG Function on the sum is just the XOR of the respective SG Fucntions, which can be proven (trivially) by the reachable set. Therefore, we can isolate the computation into smaller cases.

Two-player Zero-sum (One-step) Game

Introduction

Suppose the game is zero-sum and each player has a finite set of strategy, meanwhile each pair of strategy gives a pair of payoffs that sums to zero. What is the best strategy to take for each player?

To formulate the game, we label the players as player I (row player) and player II (column player), and denotes the payoff matrix $\{a_{i, j}\}$ where $a_{i, j}$ is the payoff to player I if player I chooses strategy $i$ and player II chooses strategy $j$.

Pure Strategy, Saddle Point

What if each player assume the worse case from the other player? Clearly if the row player chooses strategy $k$, the payoff $\min_j\{ a_{k, j} \}$ can be guaranteed. Intuitively, we can define the value $u_r(a)$ of the matrix to the row player to be the maximin $\max_k \min_j \{ a_{k, j} \}$, the maximum payoff that can be guaranteed. Similarly, we can define the value $u_c(a)$ to the column player to be the minimax $\min_i \max_k \{ a_{i, k} \}$.

Obviously, with such definitions involving inequalities, we can derive some interesting results. Is there any relation between $u_r(a)$ and $u_c(a)$? What if they are equal?

Actually this is related to the concept of saddle point $a_{k, l}$, where $a_{i, l} \le a_{k, l} \le a_{k, j}$ for all $i, j$. Note that this point is such where if only one player changes their strategy, they cannot be benefit from it. How is this useful?

First of all, $u_r(a) \le u_c(a)$, since it is impossible for the two players to guaranteed a total payoff of $\gt 0$. Second, for saddle point $a_{k, l}$, $u_r(a) \le a_{k, l} \le u_c(a)$ since $a_{k, l}$ is both a row min and column max.

Actually we can show saddle point exists iff $u_r(a) = u_c(a)$ whereas all saddle points has the same payoff as $u_r(a) \le a_{k, l} \le u_c(a)$. If saddle point exists, then trivially $u_r(a) = u_c(a)$, while on the other hand we can find a saddle point by moving within the matrix $a$.

What we have discussed are pure strategy, i.e., each player plays deterministically. What if we play mixed strategy, i.e., play each strategy with some probability?

Mixed Strategy

Consider the probability vector $\vec{x} \in \mathcal{P}^n$ where $\sum {x_i} = 1$ and $x_i \ge 0$ for all $i$. By definition, the expected payoff $\pi(\mathbf{x}, \mathbf{y})$ is $\mathbf{x}^T A \mathbf{y}$. Interestingly, there always exists optimal mixed strategy by minimax theorem. That is, there exists strategies $\mathbf{p} \in \mathcal{P}^n$ and $\mathbf{q} \in \mathcal{P}^m$ where for all $\mathbf{x} \in \mathcal{P}^n$ and $\mathbf{y} \in \mathcal{P}^m$, we have $\pi(\mathbf{x}, \mathbf{q}) \le \pi(\mathbf{p}, \mathbf{q}) = \nu \le \pi(\mathbf{p}, \mathbf{y})$.
