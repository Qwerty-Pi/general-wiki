CSCI2720 Building Web Applications

1. HTML

HTML (HyperText Markup Language) is invented by Sir Tim Berners-Lee at CERN to share scientific knowledge, maintained by W3C and WHATWG.

Common tags: <!DOCTYPE>, <head> (useful data, not shown; e.g. favicon, page title, metadata), <body> (all shown stuff),<h1> (heading), <p> (paragraph), <!-- --> (comment), <a> (link; href, target: _self, _blank).

Semantic elements: Organised into logical sections, for easier bot scraping and anchor point for styling CSS.

Image: <img src, width, height> <svg width, height><circle cx, cy, r, fill></circle></svg>

HTML Encoding: &lt; &gt; &nbsp;

HTTP Requests: GET (encode in URL: limited data size + can be bookmarked + stay in browser history / server log) / POST (data in request body: data size only limited by body size)

2. CSS and Bootstrap

CSS (Cascading Style Sheets) is for separation of content and presentation.

Override Order: External Style Sheet (.css; link, rel="stylesheet", href) < Interal Style Sheet (head) < Inline Styles (style attr) < !important

Selectors: #id, .class, tag, [attr="value"], :hover, :nth_child(3), ::first_letter

Length Units: px (pixel), em (rel. current font size), rem (rel. root font size), % (size of same prop. of parent), vh / vw (1% of viewport height / width)

Block-Level: full width, force new line; Inline: occupy content width, start anywhere

Hide Element: display: none; visibility: hidden;

Positioning: position: absolute | fixed | relative

Bootstrap: (Button) .btn, .btn-primary; (Icon) .bi, bi-airplane; (Grid) breakpoints: sm (>= 576px), md (>= 768px), lg (>= 992px), xl(>= 1200px), xxl(>= 1400px), .container-*, .row, .col-*-x (/12)

3. Javascript

Basics

Javascript: Interpreted, Single-threaded, Multi-paradigm (Object-Oriented / Imperative / Functional)

Data Types: String, Number, Boolean

String Functions: String.trim, String.split, Interpolation `\${variable}`, '/^[^\s@]+@[^\s@]+\.[^\s@]+\$/'.test (email)

Array Functions: Array.length, Array.slice(pos, len), passed by reference

Loop Object Key/Value: for (const x in/of A)

Function: function(){}, () => { return a; }, () => a;

Manipulate DOM Element: document.querySelector[All], .setAttribute, .appendChild

Fetch API: fetch(file, {method: 'GET/POST/PUT', body: '1234'}).then(res => res.text()).then(data => ...).catch(err => console.error(err))
