Floor Sum Function

We are interested about how to compute functions in the form of $$F(n, a, b, c) = \sum_{i = 1}^{n} P\Big( i, \Big\lfloor\frac{ai + b}{c}\Big\rfloor \Big)$$ where $P \in \mathbb{F}[x, y]$ is polynomial in two variables. Why, you ask? Because it appears in contests.

There are two different interpretation for this floor sum function: A 2D grid geometry one, which we can rewrite $P\Big( i, \Big\lfloor\frac{ai + b}{c}\Big\rfloor \Big)$ into summation in the y-axis such that the summation is symmetric in $x$ and $y$. Alternatively, there is also a group-theoric one, which is more generic and (possibly more) useful in scenarios.

Normalisation

We definitely don't want to handle the cases where some $a, b$ is negative or greater or equal to $c$, since those cases are ugly. How can we normalise them? We write $a = uc + a'$ and $b = vc + b'$ where $u, v \in \mathbb{Z}$ and $0 \le a', b' \lt c$. Then $$P\Big( i, \Big\lfloor\frac{ai + b}{c}\Big\rfloor \Big) = P\Big( i, \Big\lfloor\frac{a'i + b'}{c}\Big\rfloor + ui + v \Big)$$

When $P$ is of low degree, we can definitely simply do the recursion, perhaps with memorisation. Alternatively, we can breakdown $P$ into monomials, and compute all the sum over $x^ky^l$ where $0 \le k + l \lt M$ for some bounds $M$. For the sake of simplicity, denote $P_{k, l} = x^ky^l$ and the collection of all such 2D arrays of sums as $\mathbb{A}$. Suppose $F : \{(n, a, b, c)\} \rightarrow \mathbb{A} $ instead. Then (obviously) we can write $A = F(n, a, b, c)$ in form of $B = F(n, a', b', c)$, noting $$P_{k, l}\Big( x, \Big\lfloor\frac{a'x + b'}{c}\Big\rfloor + ux + v \Big) = \sum_{i = 0}^{l} \sum_{j = i}^{l} \binom{l}{j} \binom{j}{i} u^i v^{j - i} P_{k + i, l - j}\Big( x, \Big\lfloor\frac{a'x + b'}{c}\Big\rfloor\Big) $$ And so $$ A_{k, l} = \sum_{i = 0}^{l} \sum_{j = i}^{l} \binom{l}{j} \binom{j}{i} u^i v^{j-i} B_{k + i, l - j} $$ The transition clearly works in $O(M^2)$.

When $a = 0$, $P$ is just polynomial in $x$ and so such summation is easy to compute. So we may normalise such that $a \gt 0$ as well.

Geometric Interpretation

To write $P$ as summation, we can simply take the partial difference of $P$: $\Delta_y P (x, y) = P(x, y) - P(x, y - 1)$. Note that $\Delta_y P$ is also polynomial, by $$(\Delta_yP)_{k, l} = P_{k, l} - \sum_{j = 0}^{l} \binom{l}{j} (-1)^j P_{k, l - j}.$$ Hence we have $$ F(n, a, b, c) = \sum_{i = 1}^{n} \sum_{j = 1}^{\lfloor \frac{an+b}{c} \rfloor} \Delta_y P( i, j ) \Big[j \le \frac{ai + b}{c}\Big]$$ Indeed, we can rewrite the condition $j \le \frac{ai + b}{c}$ to $i \ge \frac{cj - b}{a}$. Take $m = \lfloor \frac{an + b}{c} \rfloor$, we have $$F(n, a, b, c) = \sum_{i = 1}^n \sum_{j = 1}^m \Delta_y P (i, j) \Big[ i \ge \frac{cj - b}{a} \Big] = \sum_{i = 1}^n \sum_{j = 1}^m \Delta_y P (i, j) - \sum_{i = 1}^{n} \sum_{j = 1}^{m} \Delta_y P (i, j) \Big[ i \le \frac{cj - b - 1}{a} \Big]$$

By the condition of $m = \lfloor \frac{an + b}{c} \rfloor$, $\frac{cm - b - 1}{a} \leq \frac{an - 1}{a} \lt n$. Therefore, $$ \sum_{i = 1}^{n} \sum_{j = 1}^{m} \Delta_y P (i, j) \Big[ i \le \frac{cj - b - 1}{a} \Big] = \sum_{j = 1}^{m} \sum_{i = 1}^{n} \Delta_x \widetilde{P} (j, i) \Big[ i \le \frac{cj - b - 1}{a} \Big] = \sum_{j = 1}^{m} \text{S}_y \Delta_x \widetilde{P} \Big(j, \Big\lfloor \frac{cj - b - 1}{a}\Big\rfloor\Big) = \widetilde{F}(m, c, -b - 1, a)$$ Where $\widetilde{P}$ is transpose of $P$, namely swapping $x$ and $y$.

Also note that $$ \sum_{i = 1}^n \sum_{j = 1}^m \Delta_y P (i, j) = \sum_{i = 1}^n P (i, m) $$ is "just" sum of powers. Therefore, $$ F(n, a, b, c) = \text{S}_x I(n, \Big\lfloor\frac{an + b}{c}\Big\rfloor) - \text{S}_y \Delta_x \widetilde{F}\Big(\Big\lfloor\frac{an + b}{c}\Big\rfloor, c, -b - 1, a\Big)$$

With normalisation, we can do some "euclidean-like" algorithm to solve the task.
