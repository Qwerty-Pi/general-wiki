MATH3240 Numerical Methods for Differential Equations

Introduction

Differential Equations are equations involving differentials. Ordinary Differential Equations (ODEs) are differential equations with one variable, whereas Partial Differential Equations (PDEs) are differential equations with more than one variable.

Ordinary Differential Equations (ODE)

Assume $y(t)$ is a function. An ODE is of the form $$ F(y, y^{(1)}, y^{(2)}, \dots, y^{(n)}) = 0$$ where the order of $F$ is $n$. An ODE is linear iff it is linear in $y^{(k)}$ for all $k$.

Numerical Scheme: systematic way to numerically solve equations.

Initial Value Problem (IVP): Given $x'(t) = f(x, t)$ and initial value $x(t_i) = x_i$ where $0 \le i \lt k$, solve numerically. A method is $k$-step if it involes previous $k$ values. Usually assume $t_i = t_0 + hi$.

Implicit: Computable. Explicit: Solving Equations.

Generalised k-step method: We can generalise all the k-step (linear) methods for some constants $\{a_i\}, \{b_i\}$ as in $$ \sum_{i = 0}^{k} a_i x_{n - k + i} = h \sum_{i = 0}^{k} b_i f_{n - k + i} $$

Predictor-Corrector: Use some explicit method to predict the answer, then use (iterative) implicit method to correct the answer.

Method

Grank-Nicolson Method: $x_{n+1} = x_n + \frac{h}{2} [f(t_{n+1}, x_{n+1}) + f(t_n, x_n)]$
