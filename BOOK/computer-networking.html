Computer Networking

What is computer network? For example, how does one able to see this webpage? In essense, computer network is the art of communication, despite maybe very far away from each other. More than often, we also have expectations on the network. For example, we want the message is guaranteed to be delivered, or the message is delivered fast enough, say 100s of milliseconds, or the message sent is secure and no one can temper or forge messages. Our ultimate question is: how does the modern network able to achieve all these fancy stuff?

To answer this question, we must be clear about architecture of the computer network, which the rest will be built upon. In the first part, we shall introduce the basic structure of the internet. For the second part, we will dig deep into the protocol stack of the internet in a top-down approach. Finally, in the third part we shall introduce some more applications built upon the fundamentals.

Computer Networks and the Internet

What is the Internet?

Although coined computer network, nowadays it is not just computers: We have mobile phones, laptops, game consoles, or even smart refrigerators - Everything can be linked to the internet! Therefore, we call these network-capable devices as host or end system, both carry the same meaning. In the modern internet, end systems are connected together via communication links and packet switches.

Communication links can be of different physical media, such as coaxial cable, copper wire, optical fibre or radio spectrum, which each has slightly different physical properties (of course). Messages are usually segmented into small packets with additional header bytes at the source, sent via the communication links, and is then reassembles at the destination.

Packet switches receive and forward packets to elsewhere. The most prominent types are routers and link-layer switches. Routers are more used in network cores (deep inside the network), while link-layer switches are more used in access networks (connect end system to the internet).

How does an user becomes part of the internet? We have the Internet Service Providers (ISPs), including local cable or telephone companies, or ISPs for WiFi accesses in public spaces, which provides network access to end systems. Of course, ISPs need to be inter-connected, so lower-tier ISPs are connected to national or international ISPs, forming a hierachical structure.

Finally, protocols are introduced to transfer information on the internet. Since messages are ultimately bitstrings of 0s and 1s, how can we ensure different machines "speak the same language", that is, communicate using the same format? Therefore, internet standards are developed by the Internet Engineering Task Force (IETF), where the IETF release documents as requests for comments (RFCs). Some of the well-known protocols are defined in the RFCs, such as the Transmission Control Protocol (TCP) [RFC 793], Internet Protocol (IP) [RFC 791] and Hypertext Transfer Protocol (HTTP) [RFC 2616].

We may consider the internet is an infrastructure that provides services to various applications, such as web surfing, peer-to-peer (P2P) file sharing, remote login, and many more. It would be stupid if we need to reinvent how to send message to each other for every distributed application we made! Therefore, the end systems of the internet provides Application Programming Interface (API) for delivering data, which we can rely on to develop new applications easily.

The Network Edge

Applications and end systems run at the "edge of the network" (in the spherical sense). What forms the access network, which physically connects the end system to the first (edge) router? We split into three types of access networks - home, enterprise and wide-are mobile wireless.

Access in Home

There are telephone and cable televison companies out there, both are going to be killed by the internet. How can they make more money? As the saying goes, "if you can't beat them, join them", of course by becoming Internet Service Providers (ISPs)! They are the two most prominent home access solutions these days.

First, we have the digital subscriber line (DSL) provided by the local telephone company (telco). Since the ordinary telephone channel only uses 0 to 4 kHz band of the phone line to transmit human voice, it can carry data from 4 kHz to 1 MHz band at the same time. A DSL modem (Modulator-Demodulator, digital to analogue and analogue to digital) is used to convert digital data to analogue high-frequency signals, which is then converted back to digital signals at the Digital Subscriber Line Access Multiplexer (DSLAM) at the central office (CO) of the telco. With DSL, we can reach 24 Mbps downstream and 2.5 Mbps upstream (in 2003). An older technique is dial-up, where we use the ordinary telephone channel to access the internet. Its speed is capped by 56 Kbps, and we cannot call with traditional telephone and access internet at the same time.

How about cables? Similar to DSL, we can reuse the infrastructure of the (analogue) cable television. Fibre (optic) cables is used for fast transmittion to neighbourhood-level junction (for 500 ~ 5000 homes), then coaxial (copper) cables is used to connected to each home. Therefore, it is also referred as hybrid fibre coax (HFC). We need a cable modem to convert between digital and analogue, which is connected to the computer via an Ethernet port. This is somewhat faster than DSL, and can reach 42.8 Mbps downstream and 30.7 Mbps upstream. Note that by the nature of cable television, the bandwidth is shared among the homes! Therefore, a newer technology is the fibre to the home (FTTH), directly connecting the optic fibre to the home, which can achieve an even higher speed.

As a final remark, satellite links can be used as well, such as Starlink.
